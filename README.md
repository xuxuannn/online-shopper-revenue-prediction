# Online Shopper Revenue Prediction

## English

### Overview

This project explores whether an online shopping session is likely to produce revenue. The included Jupyter notebook cleans session-level data, performs exploratory analysis, preprocesses numerical and categorical features, compares several classification models, and exports analysis-ready CSV files.

The workflow expects the **Online Shoppers Purchasing Intention** dataset as `online_shoppers_intention.csv`. That raw input file is not included in this repository; the committed CSV files are outputs produced by the notebook.

### Features

- Inspects schema, descriptive statistics, missing values, duplicates, and category values.
- Removes duplicate rows and converts selected fields to categorical data types.
- Visualizes the target distribution and relationships involving visitor type, month, weekend activity, duration, page value, and bounce rate.
- Uses a stratified 80/20 train-test split with `random_state=42`.
- Applies standard scaling to numerical features and one-hot encoding to categorical features.
- Compares Logistic Regression, Decision Tree, Random Forest, and K-Nearest Neighbours.
- Evaluates an additional SVM model separately.
- Reports accuracy, precision, recall, F1 score, ROC-AUC, classification reports, confusion matrices, and ROC curves.
- Exports cleaned data, model results, feature importance, and a Power BI-oriented dataset.

### Setup and Run

#### Google Colab

1. Open `Online_Shopping_Revenue_Prediction.ipynb` in Google Colab.
2. Run the upload cell and select a source file named `online_shoppers_intention.csv`.
3. Run the remaining cells in order.
4. Download the four generated CSV files from the final cell if needed.

#### Local Jupyter Environment

```bash
python -m venv .venv
```

Activate the environment, install the imported analysis libraries, and launch your preferred notebook interface:

```bash
python -m pip install -r requirements.txt
```

Place `online_shoppers_intention.csv` beside the notebook. The Colab upload/download cells use `google.colab` and must be skipped or replaced when running locally.

### Recorded Outputs

The committed notebook output records 12,330 source rows, 125 duplicate rows removed, and 12,205 cleaned rows. `model_performance_results.csv` contains the four-model comparison generated by the main evaluation loop; its highest recorded F1 score is 62.09% for the Decision Tree. The separately evaluated SVM is shown in the notebook but is not included in that comparison CSV or in the downstream best-model selection.

The notebook also contains rendered exploratory charts, model comparison charts, confusion matrices, ROC curves, and a Random Forest feature-importance chart. These are stored as notebook outputs rather than separate image files.

### Data and Reproducibility Notes

- The raw input dataset is required to rerun the notebook and is not present here.
- The included CSVs contain session-level behavioral fields and generated sequential session IDs; the inspected columns do not contain names, email addresses, phone numbers, or account identifiers.
- Reported metrics are the saved outputs of one stratified split, not production performance guarantees.
- Package versions were not captured by the original notebook. `scikit-learn>=1.2` is required because the notebook uses `OneHotEncoder(sparse_output=False)`.

## 中文

### 项目概述

本项目分析一次在线购物会话是否可能产生收入。仓库中的 Jupyter Notebook 完成会话级数据清理、探索性分析、数值与类别特征预处理、多种分类模型比较，并导出可供后续分析使用的 CSV 文件。

该流程需要 **Online Shoppers Purchasing Intention** 数据集，并要求原始文件名为 `online_shoppers_intention.csv`。本仓库未包含该原始输入文件；已提交的 CSV 文件是 Notebook 生成的输出。

### 主要功能

- 检查数据结构、描述性统计、缺失值、重复记录和类别取值。
- 删除重复记录，并将指定字段转换为类别数据类型。
- 可视化目标分布，以及访客类型、月份、周末活动、停留时间、页面价值和跳出率等因素。
- 使用 `random_state=42` 进行分层 80/20 训练测试拆分。
- 对数值特征进行标准化，对类别特征进行独热编码。
- 比较逻辑回归、决策树、随机森林和 K 近邻模型。
- 另外单独评估 SVM 模型。
- 输出准确率、精确率、召回率、F1 分数、ROC-AUC、分类报告、混淆矩阵和 ROC 曲线。
- 导出清理后的数据、模型结果、特征重要性和面向 Power BI 的数据集。
